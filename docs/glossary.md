# Glosario

Definiciones simples para la audiencia (estudiantes). Se muestran en la UI.

| Término | Definición simple |
|---|---|
| Tendencia | Cambio sostenido en una dirección a lo largo del tiempo. |
| Anomalía | Diferencia entre un valor y lo "normal" para esa época del año. |
| Ciclo estacional | Subidas y bajadas que se repiten cada año (verano/invierno). |
| Significancia | Qué tan seguros estamos de que la tendencia no es casualidad. |
| p-valor | Probabilidad de ver una tendencia así si en realidad no hubiera ninguna. |
| Evaporación | Agua que pasa de la superficie al aire como vapor. |
| Caudal | Cantidad de agua que fluye por un río en un tiempo dado. |
