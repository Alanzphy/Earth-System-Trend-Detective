# UI

React + Vite + TypeScript frontend. It includes a MapLibre map with [OpenFreeMap](https://openfreemap.org) vector tiles and Plotly charts (the `plotly.js-basic-dist-min` bundle, loaded lazily).

The interface is in English by default, following the Space Apps minimum requirement.

## Requirements

- Node.js 20+
- pnpm

## Local development

From `src/ui/`:

```sh
corepack enable
pnpm install
cp .env.example .env
pnpm dev
```

The UI runs at `http://localhost:5173` and expects the API at `VITE_API_BASE_URL`.

## API types

`src/types/contracts.gen.ts` is generated from `src/contracts/openapi.json` with `pnpm generate:api-types`. Do not edit it by hand; CI fails if it is stale.

## Estructura de la app

`App.tsx` monta una introducción breve, el espacio de investigación (`GuidedFlow` junto a un único `TrendMap`), resultados bajo demanda, casos reales (`DemoGallery`) y una explicación de lectura. El estado del servicio queda en el pie. No hay un segundo mapa decorativo.

- **Estado en la URL**: `?variable=&bbox=minLon,minLat,maxLon,maxLat&start=YYYY-MM&end=YYYY-MM&compare=…` (`src/lib/flow.ts`). Un enlace completo restaura y ejecuta el análisis.
- **Constructor**: selector de variable con definición, regiones predefinidas o coordenadas/dibujo bajo demanda y meses de inicio/fin. La comparación comienza con la región B vacía.
- **API**: `GET /variables` y `POST /trend` (`src/lib/api.ts`). La carga y los errores son explícitos; no se sustituyen por datos de demostración.
- **Resultado**: `LiveAnalysis` → `AnalysisResult`; conclusión primero y gráfico diferido después. `ComparisonScale` comparte la unión del rango de anomalías entre gráficos; la serie cruda opcional utiliza un eje separado.
- **Glosario**: `src/lib/glossary.ts` refleja la columna inglesa de `docs/glossary.md`; `GlossaryTerm` abre una ayuda accesible.
- **Types**: always import contract types from `src/types/contracts.ts` (aliases of the generated file).

## Demos

`public/demos/manifest.json` (`DemoManifest`) enumera los casos. Sus JSON (`Demo`) contienen uno o dos paneles y son generados por el pipeline; no se editan a mano. Las vistas previas muestran pendientes, p-valores, anomalías y tendencias desde esos mismos archivos. Abrir el caso muestra la evidencia completa; se puede cerrar sin recargar.

## Trend maps

Static trend-map files are served from `public/trend-maps/`, generated by the pipeline (`uv run python -m pipeline trend-maps`) and follow the `TrendMapManifest` v2 contract (see [`public/trend-maps/README.md`](public/trend-maps/README.md)). Entries with `"is_sample": true` would show a "Sample data" badge; the pipeline always writes `false`. Map fill and legend share the same diverging palette (`src/lib/palette.ts`): `RdBu` for temperature-like variables, `BrBG` for water-like ones, always centered at 0.

Con varios mapas, los botones cambian de variable. Cada GeoJSON se descarga solo cerca del viewport y para la variable seleccionada, sin renderizar cada celda en React. «Analyze this region» configura el constructor y analiza la celda. Un selector nativo ofrece las 20 celdas significativas de mayor cambio absoluto como alternativa de teclado. No se repite el mundo; la selección tiene contorno y las referencias geográficas quedan sobre los datos.

Para capturas locales de WebGL, `TrendMap` conserva el buffer solo cuando `import.meta.env.DEV` es verdadero. El build de producción no retiene ese buffer. Espera a que las teselas y los datos terminen de cargar antes de capturar.

## Deployment (Vercel)

- *Root Directory*: `src/ui` (the repository is a monorepo).
- `vercel.json` defines the build and output; Vercel detects Vite.
- Set `VITE_API_BASE_URL` to the public Render API URL.
- While Render wakes up (~1 min on the free plan), `ApiStatus` shows "Waking up the server…".
